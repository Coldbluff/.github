# Coldbluff

**Built is not sold. Find out where they are before you build.**

Coldbluff reads a startup idea and answers with sources. Who has the problem, in their own words, with where and when they wrote it. Who already sells them something close, and the price each one prints on its own page. Who pays, who decides, and who uses it. What argues against the idea, counted. And the one test to run next, ending in a sale. The criteria are shown before the read. Every line carries a numbered source or one of five labels, in words. If we find nothing, we say so.

The read starts in the box at [coldbluff.ai](https://coldbluff.ai). No card.

## For agents

An agent runs a read the way a person does, on the same account and the same limits. The server is at `https://coldbluff.ai/api/mcp`, and [coldbluff.ai/connect](https://coldbluff.ai/connect) has one setup per client, the sign-in and the tools. Every docs page has a markdown twin at `coldbluff.ai/docs/<slug>.md`; [`llms.txt`](https://coldbluff.ai/llms.txt) lists them, [`llms-full.txt`](https://coldbluff.ai/llms-full.txt) holds the full text, and [`changelog.md`](https://coldbluff.ai/changelog.md) says what changed, newest first. None of it needs an account.
